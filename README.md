# Gink-like 屏幕标注工具

一个类似 Gink 的 Windows 屏幕标注工具，支持在激活区域内自动切换笔/指针模式。

## 主要特性

✨ **智能激活区域**：设置一个矩形区域，鼠标进入时自动切换为笔模式，离开时切换回指针模式  
🎨 **屏幕标注**：在任何内容上进行绘制和标注  
🖊️ **可自定义**：支持自定义笔的颜色和宽度  
↩️ **撤销功能**：支持撤销最后一条绘制路径  
🗑️ **清除功能**：一键清除所有绘制内容  
📌 **系统托盘**：后台运行，随时可用  



## 使用方法

1. **启动应用**：
```bash
python gink_like_app.py
```

2. **显示绘制层**：
   - 右键点击系统托盘图标
   - 选择"显示绘制层"

3. **设置激活区域**：
   - 右键点击系统托盘图标
   - 选择"设置激活区域"
   - 点击"开始设置"
   - 用鼠标拖拽选择矩形区域
   - 设置完成后，激活区域会以蓝色虚线框显示

4. **开始绘制**：
   - 将鼠标移动到激活区域内，光标会自动变成十字（笔模式）
   - 在激活区域内按住鼠标左键拖动即可绘制
   - 将鼠标移出激活区域，光标会自动变回箭头（指针模式）
   - 此时可以正常操作其他应用程序

5. **自定义笔设置**：
   - 右键托盘图标 → "笔设置" → "选择颜色" 或 "设置宽度"

6. **清除和撤销**：
   - "清除所有"：清除所有绘制内容
   - "撤销"：撤销最后一条绘制路径

## 功能说明

### 激活区域功能

这是本工具的核心特性：
- **自动模式切换**：无需手动切换，鼠标进入激活区域自动变为笔，离开自动变回指针
- **鼠标穿透**：在激活区域外，鼠标事件会穿透到下层应用程序，不影响正常操作
- **可视化显示**：激活区域以蓝色虚线框显示，方便识别

### 使用场景

- **演示和教学**：在特定区域（如演示文稿）进行标注
- **屏幕录制**：在录制视频时进行重点标注
- **协作讨论**：在共享屏幕上进行标注和说明

## 技术说明

- 使用 PyQt5 创建透明全屏覆盖层
- 使用 Windows API 实现动态鼠标事件穿透
- 支持多显示器环境

## 注意事项

- 首次运行需要设置激活区域才能开始绘制
- 激活区域可以随时清除和重新设置
- 绘制层隐藏后，所有绘制内容会保留，再次显示时仍然可见
